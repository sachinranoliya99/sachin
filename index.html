Computer Organization & Architecture

COA Learning Rules

My study notes, organised by topic. Click any topic to expand it.

01 Learning Rules
  1. Revise the previous lecture before attending the next one.
  2. Draw block diagrams — COA is easier to understand visually.
  3. Practise number conversions daily until they become automatic.
  4. Solve at least five numericals per topic (memory, pipelining, etc.).
  5. Connect every concept to a real component inside a computer.
02 Number Systems

A number system defines how values are written using a set of digits and a base (radix).

SystemBaseDigits
Binary20, 1
Octal80–7
Decimal100–9
Hexadecimal160–9, A–F

One octal digit = 3 bits; one hex digit = 4 bits.

03 Data Representation
  • Unsigned integers use all bits for magnitude.
  • Signed magnitude uses the MSB as the sign bit.
  • 1's complement: invert every bit.
  • 2's complement: 1's complement + 1 — used by most CPUs.
  • Floating point (IEEE 754): sign, exponent and mantissa.
  • Characters are stored using codes such as ASCII and Unicode.
04 Computer Organization

Organization describes how hardware components are connected and operate, while architecture describes the attributes visible to the programmer (instruction set, addressing modes, data types).

  • Von Neumann model: CPU, memory, I/O and a shared bus.
  • System bus = address bus + data bus + control bus.
  • Instruction cycle: Fetch → Decode → Execute → Store.
05 CPU
  • ALU performs arithmetic and logic operations.
  • Control Unit generates control signals (hardwired or microprogrammed).
  • Registers: PC, IR, MAR, MDR, Accumulator, general-purpose registers.
  • Pipelining overlaps instruction stages to increase throughput.
  • Performance: CPU time = Instruction count × CPI × Clock cycle time.
06 Memory

Memory hierarchy (fastest → slowest):

RegistersCacheMain memory (RAM)Secondary storage

  • Cache mapping: direct, associative and set-associative.
  • Locality of reference: temporal and spatial.
  • Virtual memory uses paging to extend main memory.
07 Important Notes
  • 1 Byte = 8 bits; 1 KB = 1024 Bytes.
  • Range of n-bit 2's complement: −2n−1 to 2n−1 − 1.
  • Hit ratio = Hits ÷ (Hits + Misses).
  • Always write units in numericals (ns, MHz, KB).
